# Konbip

**일본 편의점 꿀조합 추천 및 공유 플랫폼**

일본 편의점 상품을 골라 나만의 꿀조합을 만들고, 영양성분을 확인하고, 다른 사람과 레시피로 공유하는 웹 서비스입니다.

| 구분 | 기술 |
| --- | --- |
| Frontend | React (Vercel 배포) |
| Backend | Spring Boot 4 / Java 21 |
| Database | MySQL 8 |
| 상품 데이터 | Tabecal API |
